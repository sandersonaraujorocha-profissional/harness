# Simplified PDF reading

Never read a binary PDF: read its `.md`, generated by a script that spends no tokens. The `.md` is the source of truth.

Converted content stays exactly as in the source: no translation, summarization, rewording, spelling correction or reordering. Never edit the generated `.md` by hand.

## Flow

For `path/document.pdf`:

1. `path/document.md` exists and its front-matter `source_sha1` equals the SHA1 of the current PDF: read the `.md`. Never open the PDF, not "to save time" nor "to ensure fidelity".
2. Otherwise run the script and, on exit code 0, read the generated `.md`:
   ```
   python .claude/skills/read-simplified-pdf/scripts/convert_pdf_to_md.py "path/document.pdf"
   ```
3. Non-zero exit: the OCR fallback got no reliable text from some pages (`.md` marked `<!-- OCR_FALHOU: pagina N -->`). Do not read or transcribe the PDF. Tell the user which pages failed and that only the model reading the PDF gets their content, which spends tokens. Read the PDF (or those pages) only after explicit authorization.

## Requirements

```
pip install pymupdf4llm pytesseract pdf2image
```

OCR runs only on pages with insufficient text and also needs the `tesseract` and `poppler` binaries on PATH. Without them, PDFs with extractable text still convert.

## Output

- `path/document.md`, with front-matter `source_pdf`, `source_sha1` and `generated_at` (ISO 8601).
- `path/<safe_name>_images/`. `safe_name`: the PDF name with every character outside `[A-Za-z0-9_]` replaced by `_` (spaces and parentheses break image saving). The script creates the folder before converting; on "No such file or directory", check or create it.
