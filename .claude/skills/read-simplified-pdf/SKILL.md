# Simplified PDF reading

Goal: never read a binary PDF directly when a `.md` faithful to its content exists (or can exist), generated without spending Claude tokens.

Messages to the user stay in pt-BR.

## Content fidelity

All converted text/content must stay exactly as in the source and unchanged: no translation, summarization, rewording, spelling correction or reordering. Do not edit the generated `.md` by hand.

## Mandatory flow

For every file `path/document.pdf` that must be read or processed:

1. Check whether `path/document.md` exists.
2. If it exists, read the `.md` front-matter and check `source_sha1`. Compute the SHA1 of the current PDF and compare:
   - If the hashes match: read `path/document.md` and use that content. Never open the PDF in this case.
   - If they differ: the PDF changed since the last conversion. Go to step 3.
3. If the `.md` does not exist or the hash is outdated, run:
   ```
   python .claude/skills/read-simplified-pdf/scripts/convert_pdf_to_md.py "path/document.pdf"
   ```
   This script is deterministic (local library) and spends no Claude tokens. On success (exit code 0), read the generated `.md`.
4. **Authorization gate.** If the script exits with a non-zero code, the OCR fallback could not extract reliable text from one or more pages (marked in the `.md` as `<!-- OCR_FALHOU: pagina N -->`). In that case:
   - Do **not** read the PDF directly or try to transcribe it on your own.
   - Tell the user which pages failed and explain that the only way to get their content is for the model to read the PDF directly, which spends tokens.
   - Proceed with direct reading of the PDF (or of the specific pages) only after the user explicitly authorizes.
5. Never trigger direct reading of the PDF by the model "to save time" or "to ensure fidelity" when the `.md` is already valid: the `.md` is the source of truth for reading.

## Script requirements

```
pip install pymupdf4llm pytesseract pdf2image
```

The OCR fallback also needs the `tesseract` (OCR) and `poppler` (page rasterization, used by `pdf2image`) binaries on PATH. Without them, the script still works for PDFs with normally extractable text; OCR is triggered only when a page has insufficient text.

## Naming convention

For `path/document.pdf`:
- Markdown: `path/document.md`
- Images: `path/<safe_name>_images/`, where `safe_name` is the PDF name with every character outside `[A-Za-z0-9_]` replaced by `_` (spaces and parentheses break image saving). The script creates the folder before converting; if it fails with "No such file or directory", check/create the folder.
- `.md` front-matter:
  ```yaml
  ---
  source_pdf: document.pdf
  source_sha1: <sha1 hash of the pdf>
  generated_at: <ISO 8601 timestamp>
  ---
  ```
