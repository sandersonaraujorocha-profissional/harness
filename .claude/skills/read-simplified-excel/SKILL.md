# Simplified Excel reading

Never read a binary spreadsheet: read its `.csv` files, generated by a script that spends no tokens. The CSVs are the source of truth.

Converted content stays exactly as in the source: no translation, summarization, rewording, spelling correction, reformatting of values or reordering. Never edit the generated CSVs by hand.

## Flow

For `path/spreadsheet.xlsx`:

1. `path/spreadsheet_csv/_manifest.json` exists and its `source_sha1` equals the SHA1 of the current spreadsheet: read the CSVs listed in `sheets[].csv`. Never open the spreadsheet, not even "to ensure fidelity".
2. Otherwise run the script and, on exit code 0, read the manifest and the needed CSVs:
   ```
   python .claude/skills/read-simplified-excel/scripts/convert_excel_to_csv.py "path/spreadsheet.xlsx"
   ```
3. Exit code 1: the CSVs were generated, but some formula cells have no calculated value saved (exported empty, listed in `formulas_sem_valor`) and are not reliable. Warn the user and suggest opening and saving the spreadsheet in Excel. Do not recalculate.
4. Read only the relevant sheets. A sheet whose `state` is not `visible` is hidden.

## Requirements

```
pip install openpyxl
pip install xlrd   # only for .xls
```

## Output

- Folder `path/spreadsheet_csv/`.
- One `<sheet-name>.csv` per sheet (UTF-8; invalid characters and spaces become `_`).
- `_manifest.json`: `source_file`, `source_sha1`, `generated_at` (ISO 8601) and `sheets[]`, each with `sheet`, `csv`, `rows`, `cols`, `state` and `formulas_sem_valor`.

## Limits

- Values only: no formatting, charts, pivot tables or macros.
- A formula comes out as its last calculated value, not as formula text.
- Merged cells: only the first cell carries the value.
