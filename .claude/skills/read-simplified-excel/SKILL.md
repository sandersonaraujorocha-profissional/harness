# Simplified Excel reading

Goal: never read a binary spreadsheet directly when `.csv` files faithful to its content exist (or can exist), generated without spending Claude tokens.

Messages to the user stay in pt-BR.

## Content fidelity

All converted text/content must stay exactly as in the source and unchanged: no translation, summarization, rewording, spelling correction, reformatting of values or reordering. Do not edit the generated CSVs by hand.

## Mandatory flow

For every file `path/spreadsheet.xlsx` that must be read or processed:

1. Check whether `path/spreadsheet_csv/_manifest.json` exists.
2. If it exists, compare the manifest `source_sha1` with the SHA1 of the current spreadsheet:
   - Equal: read the CSVs listed in `sheets[].csv`. Never open the spreadsheet.
   - Different: the spreadsheet changed. Go to step 3.
3. If the manifest does not exist or is outdated, run:
   ```
   python .claude/skills/read-simplified-excel/scripts/convert_excel_to_csv.py "path/spreadsheet.xlsx"
   ```
   The script is deterministic (local library) and spends no tokens. On exit code 0, read the manifest and the needed CSVs.
4. **Formula warning.** Exit code 1 means there are formula cells with no calculated value saved in the spreadsheet (exported empty; listed in `formulas_sem_valor` in the manifest). The CSVs were generated, but those cells are not reliable. Warn the user, suggesting they open and save the spreadsheet in Excel. Do not recalculate on your own.
5. Read only the relevant sheets. The manifest gives each sheet's name, rows and columns; sheets with `state` other than `visible` are hidden.
6. Never read the spreadsheet directly "to ensure fidelity" when the manifest is valid: the CSVs are the source of truth for reading.

## Script requirements

```
pip install openpyxl
pip install xlrd   # only for .xls
```

## Naming convention

For `path/spreadsheet.xlsx`:
- Folder: `path/spreadsheet_csv/`
- One CSV per sheet: `<sheet-name>.csv` (UTF-8; invalid characters and spaces become `_`)
- Manifest: `_manifest.json`
  ```json
  {
    "source_file": "spreadsheet.xlsx",
    "source_sha1": "<sha1 hash of the spreadsheet>",
    "generated_at": "<ISO 8601 timestamp>",
    "sheets": [
      {"sheet": "Sheet 1", "csv": "Sheet_1.csv", "rows": 10, "cols": 4,
       "state": "visible", "formulas_sem_valor": []}
    ]
  }
  ```

## Limits

- Values only: formatting, charts, pivot tables and macros are not exported.
- Formulas come out as the last calculated value, not as formula text.
- Merged cells: only the first cell carries the value.
