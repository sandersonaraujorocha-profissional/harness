# Simplified DOCX reading

Goal: never read a binary DOCX directly when a `.md` faithful to its content exists (or can exist), generated without spending Claude tokens.

Messages to the user stay in pt-BR.

## Content fidelity

All converted text/content must stay exactly as in the source and unchanged: no translation, summarization, rewording, spelling correction or reordering. Do not edit the generated `.md` by hand.

## Mandatory flow

For every file `path/document.docx` that must be read or processed:

1. Check whether `path/document.md` exists.
2. If it exists, read the `.md` front-matter and check `source_sha1`. Compute the SHA1 of the current DOCX and compare:
   - If the hashes match: read `path/document.md` and use that content. Never open the DOCX in this case.
   - If they differ: the DOCX changed since the last conversion. Go to step 3.
3. If the `.md` does not exist or the hash is outdated, run:
   ```
   python .claude/skills/read-simplified-docx/scripts/convert_docx_to_md.py "path/document.docx"
   ```
   This script is deterministic (local library) and spends no Claude tokens. On success (exit code 0), read the generated `.md`.
4. **Authorization gate.** If the script exits with a non-zero code, the document has no extractable text (content only in images, marked in the `.md` as `<!-- SEM_TEXTO -->`). In that case:
   - Do **not** read the images or transcribe them on your own.
   - Warn the user and explain that the only way to get the content is for the model to read the images, which spends tokens (see skill `read-simplified-image-diagram`).
   - Proceed only after the user explicitly authorizes.
5. Never trigger direct reading of the DOCX by the model "to save time" or "to ensure fidelity" when the `.md` is already valid: the `.md` is the source of truth for reading.

## Script requirements

```
pip install mammoth markdownify
```

## Naming convention

For `path/document.docx`:
- Markdown: `path/document.md`
- Images: `path/<safe_name>_images/`, where `safe_name` is the DOCX name with every character outside `[A-Za-z0-9_]` replaced by `_`. Created only if the document has images; referenced in the `.md` by relative path.
- `.md` front-matter:
  ```yaml
  ---
  source_docx: document.docx
  source_sha1: <sha1 hash of the docx>
  generated_at: <ISO 8601 timestamp>
  ---
  ```
