# Simplified DOCX reading

Never read a binary DOCX: read its `.md`, generated by a script that spends no tokens. The `.md` is the source of truth.

Converted content stays exactly as in the source: no translation, summarization, rewording, spelling correction or reordering. Never edit the generated `.md` by hand.

## Flow

For `path/document.docx`:

1. `path/document.md` exists and its front-matter `source_sha1` equals the SHA1 of the current DOCX: read the `.md`. Never open the DOCX, not "to save time" nor "to ensure fidelity".
2. Otherwise run the script and, on exit code 0, read the generated `.md`:
   ```
   python .claude/skills/read-simplified-docx/scripts/convert_docx_to_md.py "path/document.docx"
   ```
3. Non-zero exit: the document has no extractable text, only images (`.md` marked `<!-- SEM_TEXTO -->`). Do not read or transcribe the images. Tell the user that only the model reading the images gets the content, which spends tokens (skill `read-simplified-image-diagram`). Proceed only after explicit authorization.

## Requirements

```
pip install mammoth markdownify
```

## Output

- `path/document.md`, with front-matter `source_docx`, `source_sha1` and `generated_at` (ISO 8601).
- `path/<safe_name>_images/`, only when the document has images, referenced in the `.md` by relative path. `safe_name`: the DOCX name with every character outside `[A-Za-z0-9_]` replaced by `_`.
